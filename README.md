# AI skills

Samin's Claude skills and plugins. Each folder has a `WORKFLOW.md` explaining how it works, with a flow diagram, and what it generates.

## Skills (`skills/`)

| Skill | What it does | Generates |
|---|---|---|
| [resume-tailor](skills/resume-tailor/WORKFLOW.md) | Tailors a one-page ATS resume to a job posting from a verified master resume | `.docx` resume |
| [resume-making-assistant](skills/resume-making-assistant/WORKFLOW.md) | Fast keep/cut/backup ranking of experience, projects, coursework and skills for one posting | Short chat ranking, no file |
| [job-search-automator](skills/job-search-automator/WORKFLOW.md) | Search, filter, tailor and draft outreach, with an approval gate before anything is sent | Daily shortlist, tailored resumes, drafts, tracking log |
| [design-thinking-agent](skills/design-thinking-agent/WORKFLOW.md) | Runs nine design-research methods (SUN, CLIMBER, personas, failure ecology, etc.) | Ranked tables, interview plans, HMW statements |
| [partha-analytics-strategy](skills/partha-analytics-strategy/WORKFLOW.md) | Applies 15 consulting analytical tools | Tool write-ups, charts, so-what takeaways |
| [consulting-presentation-storyline](skills/consulting-presentation-storyline/WORKFLOW.md) | Builds McKinsey-style deck storylines | Action-title storyline, slide copy, deck critiques |
| [mckinsey-cover-letter](skills/mckinsey-cover-letter/WORKFLOW.md) | Drafts or scores MBB cover letters | 250-400 word cover letter or scored critique |
| [partha-brain-strategy-presentation](skills/partha-brain-strategy-presentation/WORKFLOW.md) | Router over the four consulting-craft references | Routed output plus checklist pass |
| [professional-writing](skills/professional-writing/WORKFLOW.md) | Memo, report and executive-summary rules for drafting or review | Drafts or quoted-and-fixed reviews |
| [technical-writer](skills/technical-writer/WORKFLOW.md) | Writes and audits technical documentation | READMEs, API docs, guides, audits |
| [avoid-ai-design](skills/avoid-ai-design/WORKFLOW.md) | Audits and rewrites generic AI-looking UI | Tell audit, design direction, rewritten code |
| [human-writer](skills/human-writer/WORKFLOW.md) | Structural anti-patterns for human-like fiction | Fiction with less AI structure |
