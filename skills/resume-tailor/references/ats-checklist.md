# ATS optimization checklist

Run every draft against this before presenting it.

## Formatting (parseability)
- Single column, no text boxes, no tables for layout, no headers/footers holding
  content the ATS must read (name/contact can live in a header only if also
  repeated in the body-readable area, or better: put contact info in the normal
  body flow, not a text-box header, since many parsers skip headers/footers/text
  boxes entirely).
- Standard section headers: "Education," "Experience" or "Work Experience,"
  "Skills," "Projects" — avoid cute renamed headers ("My Journey," "The Toolkit").
- Standard fonts (Calibri, Arial, Georgia, Times New Roman); no icons standing in
  for words (a phone icon next to the number is fine, an icon as the *only* label
  for a section is not).
- .docx is generally safer than .pdf for older ATS unless the employer explicitly
  asks for PDF — check the JD/application portal for a stated preference.
- Dates in a consistent, unambiguous format (e.g., "May 2026 – Aug 2026").
- One page. Cut before you shrink font/margins below readable (11pt body / 0.5–0.75in margins is the floor).

## Keyword coverage
- Pull the JD's exact nouns for hard skills/tools (e.g. if the JD says "SQL," use
  "SQL," not just "databases"). ATS keyword match is usually literal string match.
- Mirror the JD's exact job-family language once (e.g. if it says "Product
  Manager," make sure that phrase or a very close variant appears — in the
  summary line is a good spot).
- Spell out acronyms at least once if the JD uses both forms ("Minimum Viable
  Product (MVP)").
- Don't keyword-stuff a skills list with tools Samin hasn't actually used — every
  Core Competency listed must be traceable to a bullet or project in
  references/master-resume.md.

## Content structure that both ATS and humans reward
- Each bullet: [Result/metric] + [action verb] + [method/tool] — front-load the
  number where the master resume has one; don't bury a strong metric mid-sentence.
- No first-person pronouns, no "responsible for," no unexplained acronyms.
- Consistent verb tense per role (present for current roles, past for completed
  ones — see master-resume.md notes).

## Final pass
- Read the JD's top 5 requirements side by side with the draft resume's bullets —
  can a recruiter find evidence for each within 10 seconds of skimming? If not,
  reorder or reword until they can.
- Spell-check and check that Samin's name/contact isn't accidentally cut off by
  the one-page constraint.
