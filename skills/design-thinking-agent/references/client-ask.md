# Turning a Client's Ask into Research Questions

For the first weeks of a client project.

## Input

What the client **actually said**, verbatim if possible. If the user paraphrases, ask for the original wording (emails, brief, meeting notes), because the gap between what was said and what's meant is the point.

## Procedure

1. **(a) The real decision.** What decision is the client trying to make? (Invest or not, which segment, which concept, launch or kill, build or partner.) Distinguish the stated ask from the underlying decision. If there are several plausible decisions, name them and pick the most likely, saying why.
2. **(b) Five questions** the team would have to answer to inform that decision. Each should be answerable with evidence and decision-relevant: its answer would move the decision one way or the other.
3. **(c) For each question, the cheapest method that would answer it in two weeks with student resources.** Examples: 5–8 interviews, contextual observation/shadowing, intercept survey, desk research, competitor teardown, card sort, diary study (short), analytics review, expert calls, secondary data, a Wizard-of-Oz test.
4. **Flag** any question that cannot be answered ethically or in the time available, and say so directly (e.g., requires minors' data without consent, clinical claims, access the team doesn't have, longitudinal data). Suggest a proxy if one exists.

## Output template

```
# Client ask → research plan: [headline: the real decision]

**What the client said:** "…"
**The decision they're really making:** …
**Why we think so:** …

| # | Research question | Why it moves the decision | Cheapest 2-week method | Who/what we need | Flag |
|---|---|---|---|---|---|
| 1 | | | | | ✅ / ⚠ time / ⛔ ethics |

**Flags explained:** …
**Suggested week 1 / week 2 split:** …
**Confirm with the client:** [1–2 questions to check we read the decision right]
```

## Quality checks

- The decision is a decision (a choice between options), not a topic.
- Each question could come back with an answer that changes the decision.
- Methods are realistic for students: no paid panels, no access the team doesn't have.
- Flags are direct, not hedged.
